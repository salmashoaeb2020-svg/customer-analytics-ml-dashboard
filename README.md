# 🛒 Smart Customer & Sales Analytics Dashboard

An end-to-end Machine Learning web application built with **Python**, **scikit-learn**, and **Streamlit**. This project demonstrates the practical application of three core Machine Learning paradigms: **Clustering**, **Regression**, and **Classification** to analyze customer behavior and predict key business metrics.

## 📌 Project Overview

This dashboard provides interactive tools for e-commerce businesses to gain data-driven insights into their customer base and sales performance:

1. **Customer Segmentation (Clustering):** Grouping customers based on demographics and spending habits to identify key user segments (e.g., Target, High Spender, Conservative).
2. **Spending Prediction (Regression):** Predicting total annual customer spend or transaction value based on demographic and behavioral attributes.
3. **Purchase Likelihood (Classification):** Classifying whether a customer is likely to make a high-value purchase or unsubscribe/churn.
